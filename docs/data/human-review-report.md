## Review Workflow

To review an exercise, a human fitness expert runs:

```bash
# View an exercise
node scripts/admin/review-exercise.js <slug>

# Approve (adds approved_at and approved_by)
node scripts/admin/review-exercise.js <slug> --approve

# Reject with reason
node scripts/admin/review-exercise.js <slug> --reject --reason "Incorrect muscle classification"

# Mark needs revision
node scripts/admin/review-exercise.js <slug> --needs-revision --reason "Generic instructions need rewrite"

# View all unreviewed
node scripts/admin/review-exercise.js --list-unreviewed

# Review stats
node scripts/admin/review-exercise.js --stats
```

## Minimum Review Standards

Before approving an exercise, reviewers must confirm:

- [ ] Exercise name is accurate and unambiguous
- [ ] Category is correct
- [ ] Difficulty rating is appropriate
- [ ] Primary muscles are anatomically correct
- [ ] Secondary muscles are correct
- [ ] Execution instructions are clear and safe
- [ ] At least one breathing cue is present
- [ ] At least 2 coaching cues are present
- [ ] Common mistakes section is accurate
- [ ] Safety considerations are noted where relevant
- [ ] Equipment requirements are correct
- [ ] No proprietary content was copied
- [ ] No fabricated research citations are present
