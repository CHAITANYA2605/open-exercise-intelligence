Circus Dumbbell Clean and Press

strengthexpertcompoundoverheadunilateral

A strongman event using an oversized dumbbell that must be cleaned to shoulder and pressed overhead. The huge size makes gripping and balancing the implement uniquely challenging. Athletes typically use a combination of a swing, lap, and shoulder technique to get the dumbbell overhead.

Primary muscles

deltoid anterior
triceps long head

Secondary muscles

trapezius upper
gluteus maximus

Stabilizers

transverse abdominis

Equipment

Dumbbell (Fixed)

Starting position

  • Set up for Circus Dumbbell Clean and Press in proper strongman position.

Setup

  • Prepare all equipment and body position for Circus Dumbbell Clean and Press.

Steps

  1. Step 1: Position over circus dumbbell. Swing handle and use momentum to pull to lap.
  2. Step 2: Shoulder the dumbbell from lap position resting on forearm.
  3. Step 3: Dip slightly and drive dumbbell overhead using leg drive.
  4. Step 4: Lock out arm fully overhead before lowering.

Coaching cues

  • Use aggressive leg drive
  • Find the balanced center of the implement

Breathing

  • Brace core maximally before every lift. Breathe between reps if needed.

Range of motion

  • Full range of motion specific to the implement being used.

Tempo

  • Explosive concentric phase, controlled eccentric.

Common mistakes

  • Trying to strict press without leg drive
  • Poor grip on oversized handle

Safety

  • Use collars on all loaded barbells.
  • Ensure clear path for carries.
  • Have spotters for overhead movements.

Training

  • strength: 1–5 reps
  • power: 1–3 reps
  • strength: 3–6 sets
  • power: 3–5 sets
