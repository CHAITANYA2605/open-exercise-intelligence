## 1. Findings by Severity

### CRITICAL: 414 / 866 Exercise Files Have Invalid UUID v4 Format

**Files affected:** ~48% of the dataset  
**Example invalid IDs:** `a1b2c3d4-g007-4000-a000-000000000307`, `ex-zercher--smn-4000-a000-841923143383`  
**Root cause:** The 'g' character is not valid hexadecimal; additionally many IDs use `a000` in the variant nibble position which should be `[89ab]xxx` for UUID v4.

The `validate.js` UUID regex (`/^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i`) correctly rejects these.

**Impact:** Running `node scripts/validate.js` will produce ~414 UUID errors, causing CI to fail.

**Non-negotiable constraint:** Rule #6 prohibits assigning new IDs to existing exercises during routine data exports. Therefore, this cannot be batch-fixed without a versioned migration decision by a human maintainer.

**Recommended action (human, not auto-fixed):** Maintainer should perform a versioned ID migration — generate proper UUID v4 for all invalid-ID exercises, record the old-to-new mapping in a migration manifest under `data/migrations/`, bump the dataset version, and update `CHANGELOG.md`. This is a one-time breaking change and must be communicated to downstream consumers.

### MEDIUM: Category Field Values vs Folder Names Are Misaligned

**Observation (not auto-fixed):**  
Exercise files are stored in folders named `chest`, `back`, `arms`, `legs`, `shoulders`, `core`, `glutes`, `neck`, etc. — these are **body-part** categories. However, the JSON `category` field uses **training-modality** values (`strength`, `rehabilitation`, `stretching`, etc.).

The result: 688 exercises have `"category": "strength"` regardless of body part, making the `category` field nearly useless for filtering by body region. The `validate.js` validator enforces this training-modality scheme but the README and OpenAPI spec describe both body-part and modality filtering.

**Recommendation:** Add a separate `body_region` or `primary_muscle_group` top-level enum field to the schema to enable body-part filtering independently of training modality.
